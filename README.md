# Olive & Ember — Restaurant Website

A responsive restaurant landing page built with HTML5, CSS3, and vanilla JavaScript.

## Run locally
1. Extract `Restaurant_Website.zip`.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server (recommended), or open it directly in a modern browser.
4. Internet access is needed for the Google Fonts and remote Unsplash food photography.

## Important notes
- The reservation form is a front-end demo. It validates input and displays a confirmation, but does not send or store bookings. A backend or reservation service is required for real bookings.
- Replace the sample address, phone number, email, menu items, and prices with the restaurant's real details before publishing.
- Food images are loaded from Unsplash URLs and require an internet connection.
